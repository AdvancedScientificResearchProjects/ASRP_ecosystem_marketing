## Вариант 1 — Открыть живую версию

**<https://asrp-graph.surge.sh/preview.html>**

Размещено на бесплатном тарифе Surge.sh (24/7, неограниченный трафик, HTTPS, CDN-узлы в 10 городах). Для просмотра аккаунт не нужен.

## Вариант 2 — Запустить локально

```bash
cd graph/
python3 -m http.server 8765
# then open http://localhost:8765/preview.html in a browser
```

**Что можно делать в просмотрщике:**
- Клик по любому узлу → все поля + связи (стрелки входящих/исходящих + тип связи)
- Чипы фильтра по типам (справа вверху) → включение и выключение целых категорий
- Поле поиска → подсвечивает подходящие узлы + их ближайших соседей
- Три раскладки: `cose` (силовая), `concentric` (хабы в центре), `tree`
- Кнопка **PNG export** → сохраняет скриншот текущего вида в 2× разрешении
- Перетаскивание, масштаб, сдвиг холста
- Все 16 типов сущностей выделены цветом (см. легенду на панели)

## Вариант 3 — Импорт в Kumu.io для размещённой карты, которой можно делиться

Пошагово:

1. Зарегистрируйтесь в Kumu (бесплатно для публичных проектов): https://kumu.io/signup
2. New Project → назовите, например, *ASRP Marketing Ecosystem* → выберите **Public** (бесплатно) или Private (пробный период)
3. Нажмите зелёный **+** внизу пустой карты → **Import** → **Advanced** → **Import JSON file** → загрузите `asrp_kumu.json`
4. Kumu автоматически отрисует граф. Можно:
   - Использовать панель legend / decorate, чтобы задать цвета и формы по типам
   - Добавлять собственные поля, фильтры видов, перспективы
   - Получить публичную ссылку, которой можно делиться (в любом браузере, аккаунт Kumu у зрителей не нужен)
   - Экспортировать в PNG/SVG/PDF прямо из меню загрузки Kumu
5. Процесс повторного импорта: отредактируйте `build_blueprint.py`, перегенерируйте `asrp_kumu.json`, перетащите новый файл в проект Kumu (Kumu дедуплицирует по `id`)

## Обновление графа

Отредактируйте `build_blueprint.py` (Python — добавляет сущности и связи через две вспомогательные функции `E()` и `C()`), затем выполните:

```bash
python3 build_blueprint.py
```

Повторный импорт сохраняет ID стабильными, поэтому Kumu / preview подхватывают только изменения.

## Для чего это полезно

- **Разговоры с инвесторами и партнёрами**: откройте preview, кликните Cortical Labs → увидите исследование плазмы → Valeria как воспроизводящая → whitepaper GMS/GFS → коммерческий слой Banchenko-Market → всё на одном экране.
- **Исследование в стиле OSINT**: отфильтруйте только `outreach` + `person · external` + `institution` → увидите сеть контактов (Cortical Labs / Stanford-Nolan / NSWC IHD / DoE / NCI).
- **Проверка покрытия**: отфильтруйте `patent` и убедитесь, что каждый патент связан со своим продуктовым проектом.
- **Полнота данных**: отфильтруйте `publication` и проверьте авторство — у каждой статьи как минимум Denis в соавторах, плюс нужные члены команды.

## Заметки / открытые вопросы

- Сущность **JINR Dubna + элемент 115** включена как институциональный контекст для работы по UAP, но полный граф UAP-репозитория (хронология Lazar, архив Chernobrov, Kazatomprom и т. д.) намеренно живёт в отдельном репозитории `UAP_Reverse_Engineering_Study` по маршрутизации Denis. Этот граф ссылается на институт, но не дублирует внутреннюю сеть сущностей UAP.
- **Две компании LinkedIn + проектные группы**: вторая страница компании и дополнительные проектные группы (`ASRP.fashion` / `ASRP.drift` / `Arcanum12th`) — заготовки; заполнить, когда будут подтверждены живые URL.
- **Лог инвесторского аутрича**: узел-заглушка есть в графе; заполнить, когда Denis пришлёт исходный список контактов фондов/частных лиц.
- **Mewery Brno**: включён как заглушка до подтверждения Denis, что чешского партнёра по клеточному мясу можно называть публично.
